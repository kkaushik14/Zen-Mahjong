## Runtime Verification

Verified in the local Expo web preview, with isolated browser-origin storage rather than resetting the user's native saves:

1. First Play -> Tutorial -> matched tutorial pairs -> Continue to Practice.
2. Practice -> matched layered pairs -> Start Level 1 -> generated 36-tile board.
3. Select a tile -> Undo restores it and debits one Undo.
4. Hint highlights a useful tile and debits one Hint.
5. Shuffle rearranges the remaining board and debits one Shuffle.
6. Pause -> Save & Home -> Resume preserves the run and balances.
7. Clear Level 1 -> completion receipt with base score 10 after all three assists -> Continue starts Level 2.
8. Reload restores Level 2 and the remaining 3 Undo / 5 Hint / 1 Shuffle.
9. Restart dialog -> Cancel preserves the run.
10. Fill four regular slots with distinct identities -> recovery overlay -> Choose Tray Tile -> select Sun. The existing engine immediately resolves the special pair, reduces occupied slots to three and consumes one special use.
11. Home, Profile, Settings, Appearance, Achievements and Streaks navigation/rendering inspected at 390x844.
12. Gameplay captured at 360x800, 390x844, 412x915 and 430x932. Top controls and assist hit regions remain within each viewport. These web checks do not establish native safe-area correctness.

## Assumptions and Preservation

- The approved visual board is a composition reference, not permission to copy its example tile identities or odd example counts into gameplay. Generated board contents remain seeded and paired.
- The revised tapered shapes are implementation assumptions for the existing 36/72/144 capacities. They resemble the approved hierarchy but still require visual approval; exact pixel parity is not claimed.
- Existing saved runs keep their original geometry. Only newly created runs use the revised generator; no saves, levels or balances are reset.
- Special recovery resolves a pair immediately under the existing engine. It does not hold the chosen tile in an occupied Identity slot; no new holding rule was introduced.
- Production advertisements, purchases, backend and synchronization remain outside this corrective pass.
- The preview runs on port 8082. Updated source is not automatically present in previously installed native release builds.
