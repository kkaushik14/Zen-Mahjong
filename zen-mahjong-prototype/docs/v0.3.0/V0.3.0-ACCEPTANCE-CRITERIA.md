# v0.3.0 Acceptance Criteria

## Documentation and architecture

- Existing earlier-version documents remain unchanged.
- Runtime rules live in framework-independent packages.
- UI components do not calculate matching, rewards, inventory, or progression.
- Every persisted document declares a schema version.
- Deterministic operations store the seed and content version needed for reproduction.

## Tile catalogue

- Every design has a unique stable ID and match identity.
- Same tiles match through data rather than artwork comparison.
- Similar nonmatching tiles remain distinguishable without relying only on color.
- The generated master sheet and runtime catalogue contain the same approved entries.
- Historical sessions can resolve retired catalogue entries.

## Levels and boards

- Every tier contains eight incrementally numbered levels in the confirmed category order.
- The same seed and content version produce the same board and special-tile selection.
- Every published board has validation evidence for its declared solution contract.
- Offline users without assists receive a solution contract that does not require assists.
- Board presentation supports 36, 72, and 144 tiles without rule duplication in UI code.

## Concentration Tray

- Only eligible tiles can enter the tray.
- Regular slots preserve insertion order.
- Matching entries resolve automatically and remaining entries preserve relative order.
- Four unmatched entries enter the blocked state.
- The special slot uses the category-specific included count.
- Recovery cannot duplicate, delete, or silently change unrelated progress.

## Inventory and rewards

- First installation grants exactly 2 Shuffle, 4 Undo, and 6 Hint.
- Sign-in or reload cannot reset or duplicate inventory.
- Every inventory change has one local ledger entry and idempotency identity.
- Achievement rewards are automatic and granted once.
- Undo restores all state belonging to the undone transaction.

## Score and progression

- All eight assist combinations produce the approved base score.
- All combinations are eligible for the time bonus.
- Exactly 10 seconds faster awards `+1`; less than 10 seconds awards `0`.
- Background time is excluded.
- The first completed level receives no comparison bonus.
- Scores above 20 display their actual value and overflow state.
- Concentration Score is calculated only after all eight tier levels.
- Exactly `.5` rounds down.
- Completion advances to the next incremental level without exposing Replay.

## Persistence and offline operation

- Tutorial, practice, gameplay, scoring, progression, achievements, and recovery work without network access except explicitly online advertisement actions.
- Active state restores after termination during selection, tray insertion, pair resolution, revival, scoring, and completion.
- Corrupt current data falls back to a validated previous snapshot or documented safe default.
- Duplicate completion and achievement receipts have no additional effect.
- Future-sync events can be recorded without requiring a server.

## Accessibility and layout

- Tap provides every interaction available through drag.
- Tile and tray state is not communicated by color alone.
- Screen readers receive tile identity, availability, tray position, and action results.
- Reduced Motion removes nonessential movement while preserving state feedback.
- Supported phone and tablet layouts avoid overlap and preserve practical hit targets.

## Performance and device gate

- Home normally launches within 3 seconds and within 5 seconds on minimum devices.
- Resume completes within 1.5 seconds under the defined test protocol.
- Gameplay targets 60 FPS with no sustained interaction-blocking frame drops.
- Normal memory remains below 250 MB, temporary peaks remain below 350 MB, and repeated levels do not show continuing growth.
- A controlled 30-minute session uses approximately 5% battery or less without thermal warnings under the documented device protocol.
- Physical iOS and Android runs cover tutorial, one tier, offline launch, background timing, recovery, and persistence.
