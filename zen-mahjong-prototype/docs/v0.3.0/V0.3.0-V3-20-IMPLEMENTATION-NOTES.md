# v0.3.0 V3-20 Onboarding Preservation and End-to-End Integration

Date: 2026-10-07 (Asia/Kolkata)

## Scope

V3-20 preserves the existing Tutorial and Practice presentation while making their required sequence authoritative across Home, direct route entry, process restoration, and numbered gameplay. It also adds an executable first-install-to-second-tier integration contract and removes confirmed-unused suffixed source copies.

This document is additive. Earlier version and milestone documents are unchanged. Runtime asset pruning remains the separate V3-20A milestone.

## Onboarding contract

The shared onboarding state machine resolves exactly one next destination:

1. Restore an active numbered run at `/game`.
2. Restore an active Tutorial or Practice session.
3. Require Tutorial when it has not been completed.
4. Require Practice after Tutorial.
5. Allow numbered gameplay after both training steps.

Home and Gameplay use the same resolver. Direct entry to Gameplay cannot create Level 1 before the required training sequence. Direct entry to Practice returns an untrained player to Tutorial.

Tutorial and Practice keep their preserved pre-Moonlit presentation under conflict D-01. They still use the real board availability, tray insertion, matching, special slot, and free Hint behavior. Neither training mode consumes permanent assists, awards score, advances progression, or changes streaks.

Completed players can review Tutorial from Settings. Review sessions are intentionally ephemeral: they do not replace an active numbered run, reset onboarding completion, consume inventory, or alter progression.

## Returning-player preservation

When persisted numbered-play evidence exists but the separate onboarding document is missing or incomplete, hydration marks Tutorial and Practice complete using the latest persisted completion or active-run timestamp. This reconciliation only applies when one of these signals exists:

- an active numbered run;
- at least one completion receipt; or
- a current level greater than 1.

A fresh Level 1 save without numbered-play evidence remains a first install and must complete Tutorial and Practice.

The existing schema-one to schema-two offline migration preserves the complete economy and progression aggregates while adding only the advertisement receipt state. Tests assert that the initial assist transaction remains once-only and that migration does not duplicate inventory.

## End-to-end contract

The integration test exercises:

- first install to Tutorial;

- Level 9 active-run restoration;
