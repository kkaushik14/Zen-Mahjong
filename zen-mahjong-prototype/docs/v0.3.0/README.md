# Zen Mahjong Prototype v0.3.0 Documentation

## Versioning policy

This directory is the documentation baseline for `v0.3.0`.

- Existing documents outside this directory are historical records and must not be overwritten to describe `v0.3.0`.
- Later versions must receive a new directory such as `docs/v0.4.0/`.
- Corrections within this version should be recorded in a new dated addendum or superseding versioned document when they materially change an approved rule.
- Runtime implementation must cite the applicable versioned rule or decision identifier.

## Scope

`v0.3.0` delivers the offline-complete Concentration gameplay system, deterministic level content, local progression, assists, Zen Score, achievements, tutorial, responsive presentation, and device QA.

Backend hosting, production account synchronization, cloud retention enforcement, and production advertisement verification are deferred. Interfaces and local receipts may be created so those systems can be added later without moving game rules into the presentation layer.
