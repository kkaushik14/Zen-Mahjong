# v0.3.0 V3-13 Artwork Reconciliation

Date: 2026-10-07 (Asia/Kolkata)

## Authority and scope

The [Tile Artwork Production Brief](V0.3.0-TILE-ARTWORK-PRODUCTION-BRIEF.md) remains authoritative for gameplay identity: 36 regular designs, eight Special designs, and six reserve/event designs. Exact matching uses `matchIdentity`; similarity groups and visual appearance never create a match.

The frozen Figma export supplies 50 polished artwork components, but its motif list diverges from the production brief after the initial set. V3-13 therefore keeps two independent registries:

- The gameplay catalogue defines what a tile means and whether it may enter a level.
- The artwork registry defines what images exist and where each image came from.

An artwork is bound to a gameplay identity only when the subject is semantically equivalent. Approximate substitutions are not allowed.

## Exported artwork

All 50 Figma motifs are extracted from five frozen transparent atlases into individual 256 x 256 PNG files. Each manifest entry records the Figma component ID, source image hash, normalized crop converted to pixel bounds, source size, output size, semantic artwork ID, and runtime path.

The extraction isolates the primary alpha-connected motif before downsampling. This prevents fragments from neighbouring atlas cells from entering runtime tiles.

The two squirrel artworks remain separate identities:

- `42-squirrel-branch`
- `49-squirrel-log`
