# v0.3.0 V3-11 Asset Readiness Manifest

Date: 2026-10-07 (Asia/Kolkata)

## Classification rules

- **Runtime-ready candidate:** a complete image with a clear runtime role, pending on-device crop and quality verification.
- **Composable source:** useful source material or an atlas that must be extracted, mapped, optimized, and visually verified before runtime use.
- **Reference-only:** a source sheet or crop that may contain captions, presentation backgrounds, checkerboards, or unrelated artwork.
- **Blocked:** not permitted in the build until clean extraction, licensing, or design approval resolves the blocker.

Nothing under `docs/v0.3.0/design-baseline/` may be imported directly by application code. V3-12 must copy only approved derivatives into `apps/mobile/assets/` and register them by stable semantic ID.

## V3-12 import gate

Every accepted runtime image must receive: semantic ID, originating Figma node, source hash, crop bounds, native dimensions, aspect ratio, target density, optimized file size, alpha inspection result, light/dark-background inspection result, and runtime destination. No raw hash or documentation path may appear in screen code.
