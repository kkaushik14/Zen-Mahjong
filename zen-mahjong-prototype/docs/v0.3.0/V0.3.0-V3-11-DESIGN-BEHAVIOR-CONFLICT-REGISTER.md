An open gate blocks only the affected behavior or visual element. It does not authorize a guessed implementation. Owners record resolutions in a new dated addendum or milestone note; historical documents remain unchanged.

## Confirmed precedence decisions

- Game and economy rules decide behavior.
- The frozen Figma export decides visual composition and approved screen inventory.
- Existing framework-independent engine and persistence contracts own state transitions.
- Figma values such as level, score, streak and achievement counts are fixtures.
- Backend, OAuth, cloud sync, purchases and production ad SDK work remain excluded from this pass.
