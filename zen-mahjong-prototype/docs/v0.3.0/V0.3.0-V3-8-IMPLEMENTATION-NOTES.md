# v0.3.0 V3-8 Tutorial and Presentation Implementation Notes

## Scope

Milestone V3-8 connects the v0.3.0 Concentration engine, local economy, timing, progression, and persistence aggregate to the Expo presentation layer. It adds the first-install tutorial, assisted practice, numbered gameplay, Concentration tray, blocked and failed recovery, score completion, tier progress, streaks, achievements, accessibility state, and Reduced Motion behavior.

This is a new v0.3.0 implementation record. Earlier-version documents remain unchanged. Production advertisements, purchases, account synchronization, final Special tile artwork, and physical-device performance sign-off remain outside this milestone.

## First-player path

Home enforces the following offline path without exposing numbered progression early:

1. Guided Tutorial.
2. Assisted Practice.
3. Numbered Level 1.
4. Incremental levels with no Replay action.

Tutorial and practice use real Concentration selection, availability, tray insertion, and automatic pair-resolution rules. Their Hint action is free. They never read or mutate permanent assist inventory, Zen Score, streak rewards, achievements, completion receipts, or numbered progression.

Training completion and the active training board are stored in the versioned `onboarding-state:v0.3.0` document. Termination during training restores the board and tray. Completing Tutorial leads to Practice; completing Practice leads to Level 1. Settings provides a deliberate Tutorial review entry without resetting completion or economy.

## Numbered gameplay integration

- Board taps execute tracked Concentration commands; the UI does not calculate matches.
- Four stable regular tray slots display insertion order.
- Matching identities resolve automatically through engine events.
- The separate S slot displays remaining Special Concentration uses.
- When the regular tray is blocked, the recovery panel sends the player back to choose a tray tile for the special-slot command.
- A failed board offers Restart and score-funded Revive when the balance permits it.
- Hint, Shuffle, and Undo display ledger-derived balances and are disabled when unavailable.
- Restart, revival, assists, selection, and special-slot use commit through the atomic offline aggregate.
- App background transitions pause foreground timing; returning active resumes a recoverable session.

## Completion and progression presentation

The final match produces a versioned completion receipt and then clears the active run in the same aggregate commit. The completion view displays:

- Actual Zen Score.
- Active foreground time.
- Position in the eight-level tier.
- Confirmed stepped Zen milestone progress.
- A distinct above-20 overflow message.
- Tier Concentration Score when level eight completes.
- Automatic achievement IDs granted by the transaction.

The only forward gameplay action is Next Level. Home shows current tier, level, category, streak, spendable Concentration Score, and whether the current run can be resumed.

## Streak and achievement presentation

Opening the application records one idempotent device-local daily visit through the v0.3.0 progression engine. The same local date cannot increment the streak twice. The visit and any automatic reward are committed with the gameplay aggregate, and a future-sync streak event is queued.

The Streak screen shows current and best streak plus the confirmed 7-, 14-, and 21-day reward milestones. The Achievement screen derives unlocked state from once-only ledger transaction IDs and displays all confirmed streak and Concentration Score thresholds through 200.

## Accessibility and motion

- Every board tile exposes its identity and available or blocked state in its accessibility label.
- Tray tiles announce their regular slot position and Special-slot action when blocked.
- Empty tray slots and remaining special uses are announced.
- Every drag-equivalent game action is available through a tap.
- Feedback regions use polite live announcements.
- Tile identity and state use shape, labels, borders, and opacity rather than color alone.
- Controls retain practical hit areas; tile controls include additional hit slop.
- Reduced Motion removes board entry, removal, layout, hint pulse, and modal fade animation while preserving state changes.
- The shared screen container expands from phone width to a constrained 760-point tablet layout.

## V3-8 content assumption

The approved v0.3.0 catalogue does not yet contain reviewed Special tile designs. Numbered presentation therefore uses the deterministic reviewed 36-tile `garden-two` fixture for all eight category positions, with a level-specific seed and category behavior. This allows the complete tier, tray, score, and progression workflow to be exercised without inventing production tile art.

This fixture is marked `0.3.0-presentation-fixture` in every session. It must be replaced by V3-3 generated content after at least four Special designs pass catalogue and master-sheet review. The engine, catalogue generator, and production gate remain unchanged.

## Other assumptions and boundaries

- Tutorial and Practice use small reviewed fixtures rather than numbered content and do not issue receipts.
- Leaving a numbered board for another in-app screen does not pause timing; only application background state pauses it, matching the confirmed timing rule.
- V3-8 records completion and streak outbox events. A future synchronization adapter will define complete event expansion and acknowledgement retention.
- Revival advertisement actions remain deferred to V3-9. Offline Restart remains available when the player cannot afford Revive.
- Final tablet density, screen-reader traversal on physical devices, and performance for 72- and 144-tile boards remain V3-10 device gates.
