# v0.3.0 V3-12 Implementation Notes

Date: 2026-10-07 (Asia/Kolkata)

## Status

**Complete.** V3-12 establishes the Moonlit Garden foundations, exact bundled font aliases, semantic runtime-asset registry, startup preloading, responsive helpers, and Reduced Motion durations. No game rule, progression, persistence contract, route, or public screen composition changed.

## Implemented foundations

### Design tokens

`packages/design-tokens/src/index.ts` now contains:

- The approved primitive and semantic color values from the frozen Figma manifest.
- The complete spacing values `4`, `8`, `12`, `16`, `20`, `24`, `32`, `40`, `48`, and `64`.
- Compact, tile, card, modal, and full-radius tokens.
- iOS and Android minimum touch sizes and the approved control size.
- Tile, selected, card, and modal shadow definitions.
- Stable font-family aliases for the four approved typefaces.
- Semantic motion durations plus `resolveMotionDuration`, which reduces decorative timing to zero when Reduced Motion is enabled.
- Phone bounds for 360, 390, 412, and 430 point/pixel compositions while preserving the existing functional tablet maximum.

Existing typography consumers now resolve headings through the bundled display family instead of the platform-dependent generic `serif` name. Body and control styles resolve through the bundled Inter alias.

`apps/mobile/src/theme/responsive.ts` provides:

- Approved reference widths.
- Compact and standard content gutters without viewport-scaled typography.
