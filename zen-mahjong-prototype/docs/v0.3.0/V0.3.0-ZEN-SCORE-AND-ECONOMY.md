# v0.3.0 Zen Score and Economy

## Score precedence

`Used` means the assist was consumed at least once during the completed level.

| Case |   Undo   |   Hint   | Shuffle  |    Base Zen Score | Time bonus eligible |
| ---: | :------: | :------: | :------: | ----------------: | :-----------------: |
|    1 |   Used   |   Used   |   Used   |                10 |         Yes         |
|    2 |   Used   |   Used   | Not used |                18 |         Yes         |
|    3 |   Used   | Not used |   Used   |                15 |         Yes         |
|    4 | Not used |   Used   |   Used   |                14 |         Yes         |
|    5 |   Used   | Not used | Not used |                18 |         Yes         |
|    6 | Not used |   Used   | Not used |                15 |         Yes         |
|    7 | Not used | Not used |   Used   |                14 |         Yes         |
|    8 | Not used | Not used | Not used | 18 before bonuses |         Yes         |

The table is authoritative. More specific rows take precedence over general phrases such as "completed without Hint."

## Completion timing

- Timing starts when active gameplay begins.
- Timing stops when the last required tile pair resolves.
- Background and inactive time does not count.
- Returning to the foreground resumes active timing.
- The timer need not be displayed during gameplay.
- Completion results display the recorded active duration.
- Completing a level at least 10 seconds faster than the immediately previous completed level awards `+1` Zen Score.
- Finishing more than 10 seconds faster still awards only `+1`.
- The first completed level has no comparison and receives `0` time-comparison bonus.

## Advertisement effects

| Advertisement result                | Zen Score effect | Limit                          | Included in final score |
| ----------------------------------- | ---------------: | ------------------------------ | :---------------------: |
| Assist reward successfully granted  |               +1 | Unlimited in current direction |           Yes           |
| Revival successfully granted        |                0 | Not a score bonus              |           No            |
| Failed, cancelled, or unverified ad |                0 | Not applicable                 |           No            |

Production advertisement qualification and duplicate-prevention rules remain deferred to the advertisement implementation segment.

## Final Zen Score

```text
Final Zen Score =
  base score from the precedence table
  + faster-completion bonus
  + qualifying assist-ad bonuses
  + future explicitly approved bonuses
```

There is no mathematical maximum. A score above `20` adds no separate bonus. The interface displays the actual value and uses an overflow treatment because the standard progress scale ends at `20`.

## In-game Zen milestones

The per-game progress presentation resets for each game and stores the final value for tier calculation.

| Zen Score |                Display milestone |
| --------: | -------------------------------: |
|         3 |                              10% |
|         6 |                              20% |
|        10 |                              50% |
|        20 | Almost 100% / standard-scale end |
|  Above 20 | Overflow state with actual score |

These percentages are presentation milestones, not a linear score formula.

## Concentration Score

- Concentration Score is calculated only after all eight levels in a tier are completed.
- The tier score is total Zen Score across those eight levels divided by eight completed levels.
- Fractional results below `.5` use floor.
- Fractional results exactly equal to `.5` use floor.
- Fractional results above `.5` use ceiling.

```text
Concentration Score = tier Zen Score total / 8
```

## Revival sequence

Concentration Score revival prices within one game are:

```text
10, 15, 25, 40, 50, 65, 75, 90, ...
```

After the initial `10` and `15`, alternate adding `10` and adding `15` to the last quoted price.
