# v0.3.0 V3-19 Implementation Notes

## Scope

V3-19 implements Board Complete, Achievements, Achievement Detail, and Streaks from the existing device-local completion receipts, economy ledger, tier awards, and visit calendar. No backend, claim action, replay flow, or new reward rule was introduced.

## Board Complete

- The completion route receives only the persisted receipt ID. Score, duration, assist usage, time bonus, advertisement bonus, level transition, tier position, tier award, and newly granted achievements are reconstructed from the local offline aggregate.
- Direct navigation without a valid receipt displays a neutral recovery state and cannot mutate progression.
- Continue opens the current incremental game route. Home leaves the summary. No Replay action exists.
- Zen Score remains numerically visible above 20 while the progress presentation is capped at 20.
- The lotus entrance uses opacity and scale through the native animation driver. Reduced Motion renders the final state immediately. Receipt persistence occurs before navigation and is never delayed by presentation motion.

## Achievements

- The engine now exports its read-only achievement reward definitions so the UI and rule implementation share one reward authority.
- The screen lists all nine confirmed streak and Concentration Score achievements. Figma counts and titles are treated as fixtures under D-14.
- Unlocked state comes only from once-only `achievement:*` economy transactions. Locked progress comes from current visit streak or lifetime Concentration Score.
- Selecting a row opens the approved local detail modal. The modal is informational; rewards are automatic and cannot be claimed twice.

## Streaks

- Current streak, best streak, last device-local visit, and milestone progress come from the same progression aggregate used by automatic rewards.
- The week and month views derive contiguous played dates from the current streak ending at `lastVisitLocalDate`. Earlier historical activity is not fabricated because v0.3.0 does not persist a full visit-history collection.
- Calendar calculations use the device-local date and Monday-first presentation. Confirmed reward milestones remain 7, 14, and 21 days.
