## Assumptions and decision gates

- The frozen 2026-10-07 design export remains the visual authority because live Figma file access was unavailable.
- The Home daily target is presented as four activities, matching the approved design. This is presentation-only until Daily Challenge rules and persistence are finalized.
- Journey `Stage` maps to the current eight-level tier number. The Journey destination is noninteractive until its screen and navigation behavior are approved.
- The achievement denominator uses the implemented catalogue count, currently four, rather than the design fixture value of twenty-four.
- The HUD currency is the available Concentration Score. Its artwork includes a plus symbol, but purchasing is not interactive before the in-game purchase decision is approved.
- A first daily visit may show a one-day streak because V3-6 records day one during local hydration.
- Loading progress is a brief branded startup presentation, not network or byte progress. Local data has already hydrated before this React screen is mounted.
- The Loading composition appears once per JavaScript application lifecycle. Returning from another route does not replay it.
- The settings stepping stones and other scenery remain background artwork, not touch targets.

## Generated Home assets

Assets are generated in `apps/mobile/assets/artwork/home/v3/`. The adjacent `manifest.json` records the Figma node ID, source hash, crop, dimensions, and runtime path for each item. Regenerate with:

```bash
PATH=/opt/homebrew/opt/node@24/bin:$PATH node scripts/extract-home-assets.mts
```
