## Method

The frozen PNG is the visual reference, not a runtime asset. Later milestones must capture the real application at the exact viewport, compare composition and crop, and separately verify behavior, accessibility, scrolling, and safe areas. Fixture text and values are replaced with deterministic test-state values.

## Comparison checklist

- Safe-area and system-bar clearance.
- Background aspect ratio, crop anchor, and absence of stretching.
- Native text baseline, wrapping, truncation, contrast, and dynamic values.
- Panel, branch, tile, tray and control alignment.
- Minimum touch targets and screen-reader order.
- Pressed, disabled, zero-balance, selected, hinted, loading and recovery states.
- Reduced Motion behavior without layout jumps.
- Settings scroll reaches every retained row at every reference height.
- No checkerboard, source caption, halo, sheet background, or unrelated crop content.
- No memory growth during repeated navigation and level completion.

## Additional non-pixel checks

- Tutorial and Practice are behavior-tested but excluded from visual conformance until approved V3 frames exist.
- Tablet retains functional adaptive behavior but cannot pass V3 pixel conformance without tablet designs.
- Physical-device FPS, memory, battery, resume timing, offline restoration, migration, and accessibility remain V3-21 gates.
