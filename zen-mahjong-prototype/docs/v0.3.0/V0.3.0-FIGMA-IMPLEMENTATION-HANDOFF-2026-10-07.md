## 4. Visual Implementation Rules

- Read actual exported layer bounds, constraints, font styles, fills and variables. Do not rely only on stored plugin reports, which can predate manual edits.
- Known reference phone sizes are 360 x 800, 390 x 844, 412 x 915 and 430 x 932. First Play is an additional state, not an additional application destination.
- Match each exported phone layout individually, then use responsive constraints between them. Avoid stretching the complete screen uniformly.
- The latest previously inspected Home has Journey and Achievements side by side; Continue follows with breathing room; Settings sits centered below Continue; currency occupies the upper-right area with a proper margin. Preserve this only where confirmed by the fresh export. Earlier numeric spacing rules must not override manual edits.
- Keep controls independent of the illustrated stepping stones. Respect OS status/navigation areas and bottom safe-area insets without adding visible sections.
- Use shared native layout and real interactive controls. Keep text, balances, progress, selections and settings editable/data-driven, not baked into images.
- Preserve image aspect ratios and approved crop positioning. Do not stretch branches or marble frames to force a fit; use separate edges only when a reviewed asset supports that construction.
- Use the fonts and exact style names from each exported layer, not one global font substitution. Current screen layers use `Cormorant Garamond / Medium`, `Inria Serif / Regular`, `Inter / Regular` and `Irish Grover / Regular`. The fresh export includes the user's popup typography changes; earlier Cormorant-only assumptions must not override them. Check licensing and bundle availability before shipping fonts.
- Reserve practical touch targets, at least 44 points on iOS and 48 dp on Android where feasible. Hit slop may enlarge targets without changing artwork placement.
- Preserve readable contrast, screen-reader order, focus behavior and Reduced Motion. If a required accessibility adaptation materially changes the composition, record it for approval rather than silently redesigning.
- Text expansion must not overlap flowers, frame edges, neighboring controls or values. Do not reduce text arbitrarily to hide a layout defect.
- Settings must genuinely scroll; content below the first viewport is not missing. Use the full-scroll export to verify all retained rows.
- New tablet compositions, landscape layouts and alternate visual themes are not approved by the phone mockups. Request design guidance where the existing product requirements exceed the exported coverage.
