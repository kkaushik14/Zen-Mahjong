## Defects resolved during QA

- Enabled the generated iOS target for iPhone and iPad and regenerated build metadata from app version `0.3.0`, build `3`.
- Aligned five Expo SDK 57 packages to the versions required by Expo Doctor.
- Ported the existing path-safe Xcode patches to the new Expo Constants and Expo Updates patch versions.
- Deduplicated the transitive native Expo Constants installation through a workspace override.
- Removed stale `index 2.tsx`, `rules 2.ts`, and `rules.test 2.ts` copies; the accidental `/index 2` export route is gone.
- Reinstalled a corrupted generated `node_modules` tree containing 11,452 byte-identical suffixed dependency files, then completed CocoaPods installation successfully.

## Observations

- The iPad layout is readable and does not overlap, but the phone-width content column leaves substantial unused lower space. This is a polish item, not a functional release blocker.
- A local non-EAS release launch records an Expo Updates `400` because no `expo-channel-name` header is injected. The embedded bundle still launches. The configured EAS profiles supply release channels and must be verified in the final EAS build.
- iOS 27 emits upstream status-bar deprecation messages from the React Native/Expo stack; no application crash was observed.
- Simulator UI automation could not attach to Xcode Device Hub, so tile taps, tray behavior, full-tier completion, background timing, and restore behavior remain manual-device gates rather than inferred passes.

## Manual physical-device protocol

1. Install the current development build without deleting previous v0.2.0 local data.
2. Confirm migration restores or archives the prior session without duplicating initial inventory.
3. Complete Tutorial and Practice, terminate during each, and verify restoration.
4. Complete levels 1 through 8 without Replay appearing.
5. Exercise Hint, Shuffle, Undo, Restart, Special-slot recovery, score revival, and fake-ad reward paths.
6. Background the app for at least 30 seconds during a level and confirm background time is excluded.
7. Terminate after a tray insertion, pair resolution, revival, and final match; confirm one valid recovered state.
8. Disable connectivity and repeat launch, gameplay, completion, progression, and recovery.
9. Enable Reduced Motion and screen reader, then verify traversal order, labels, action feedback, and practical hit targets.
10. Run the 30-minute battery, thermal, memory, and frame-rate protocol on both physical platforms.
