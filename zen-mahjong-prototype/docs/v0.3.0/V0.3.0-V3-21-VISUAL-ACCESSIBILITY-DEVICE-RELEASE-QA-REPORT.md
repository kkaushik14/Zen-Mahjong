## Defects resolved during V3-21

1. Added native accessibility focus when the Appearance and reward-ad modals open.
2. Replaced fixed achievement/streak presentation heights with dynamic minimum heights.
3. Corrected React Compiler asset-source reuse that repeated the first frame image across wide buttons, mini cards, modal edges, compact actions, assists, and textured surfaces.
4. Repaired Home frame rendering and verified unique left, middle, and right assets at runtime.
5. Added a web viewport-height contract so Profile and other secondary pages cannot expose an unpainted lower band.
6. Replaced the long-panel `ImageBackground` with an absolute Expo image so artwork follows all scroll content.
7. Regenerated a clean iOS CNG project after the generated native tree contained Finder-style duplicate projects, Pods, and files; CocoaPods then installed 118 pods successfully.

## Production blockers and approved scope limits

- Physical iOS and Android protocols are not complete.
- VoiceOver, TalkBack, maximum dynamic text, battery, thermal, memory, and FPS gates need device evidence.
- Numbered levels 7 and 8 retain the documented 36-tile fallback until at least four approved Special Concentration artworks exist.
- Production advertisement SDK and reward verification are not selected; only the adapter/fake-provider path is approved.
- Backend synchronization, OAuth, purchases, and account recovery remain outside this offline prototype release.
- Tutorial and Practice preserve the approved existing experience because replacement V3 design frames were not supplied.
- Tablet behavior is adaptive but does not have an approved pixel-conformance reference.
- Development and preview EAS cloud builds must be regenerated from the final commit after the blockers above are accepted or closed.

## Manual release protocol

1. Install the final development build on both physical targets without deleting prior local data.
2. Verify migration, tutorial, practice, levels 1-8, assists, recovery, score, achievements, streaks, and force-quit restoration.
3. Repeat launch, gameplay, completion, and restoration with connectivity disabled.
4. Exercise 36-, 72-, and 144-tile boards with Reduced Motion both off and on.
5. Run VoiceOver and TalkBack traversal, modal focus, state announcements, and maximum-text-size checks.
6. Run launch/resume, 30-minute FPS, memory, battery, thermal, and repeated-level-growth measurements.
7. Produce final EAS development and preview builds and record their build URLs and checksums here.

## Verdict

The v0.3.0 implementation is a verified local release candidate, not a production-approved release. V3-21 remains open until physical-device, accessibility, performance, content, and production-service blockers are either passed or explicitly approved as release exceptions.
