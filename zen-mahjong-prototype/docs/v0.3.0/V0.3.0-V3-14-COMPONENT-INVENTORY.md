## Release boundary

The component specimen remains in `apps/mobile/src/features/component-gallery/` for development review, tests, and future screenshot tooling. It has no Expo Router route and no settings link, so release navigation and production bundles do not expose it.

The V3-11 terminology decision between Identity and Special Concentration remains open for V3-16. V3-17 still owns final popup variants and their product-state bindings. V3-13 artwork approval limitations remain unchanged.
