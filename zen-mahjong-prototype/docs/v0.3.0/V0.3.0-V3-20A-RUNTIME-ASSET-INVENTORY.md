## Automated audit

Run `pnpm assets:audit` from the repository root. The audit fails when:

- a static registry or Expo configuration asset is missing;
- a generated manifest output is missing or has the wrong content version;
- a removed starter asset or `tabIcons` file returns;
- runtime source references `docs/`, Downloads, or temporary filesystem paths;
- two retained runtime binaries have the same SHA-256 hash.

Current result: 101 inventoried files, 96 unique binaries, and 15,107,518 binary bytes.
