## Runtime architecture

`packages/game-content` owns tile meaning, matching, release role, eligibility, and approval. `packages/mahjong-ui` owns static image resolution and presentation. The engine never derives matching behavior from an image, filename, color, family, or similarity group.

The extraction command is:

```bash
PATH=/opt/homebrew/opt/node@24/bin:$PATH node scripts/extract-tile-artwork.mts
python3 scripts/generate-tile-review-sheets.py
```

The master-sheet command is unchanged:

```bash
pnpm content:master-sheet
```

It now targets `V0.3.0-V3-13-TILE-MASTER-SHEET.md` and verifies identical content instead of overwriting a changed versioned artifact.
