## Figma Structure

- `01 Foundations` - semantic color variables, spacing, radii, typography, elevation, and usage rules.
- `02 Components` - tile states, artwork, controls, navigation, cards, settings, achievements, calendar, dock, and modal variants.
- `03 Screens` - loading states, Home, Gameplay, Profile, Settings, Completion, Achievements, Streaks, responsive gameplay, and the app-flow wireframe.
